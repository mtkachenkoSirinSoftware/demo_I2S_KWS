# demo_I2S — детальный план реализации

Always-on KWS на Apollo510 EVB с I2S-микрофоном и дашбордом. Прошивка
собирается через nsx (neuralspotx), как `ambiq_kws_examples/kws_pdm`.

Этот документ заменяет предыдущую версию плана и расходящиеся с ним места
[PLAN.md](PLAN.md). Что из него сделано — в разделе «Состояние» ниже.

## Состояние на 2026-10-09

Прошивка и дашборд реализованы и проверены на плате без речи; проверку
распознавания голосом должен сделать человек у микрофона.

| Этап | Состояние | Чем подтверждено |
|---|---|---|
| M0. Каркас | сделано | сборка через nsx в контейнере; баннер и SHA модели на SWO; 88 тестов копии `kws_core` проходят |
| M1. Звук I2S | сделано | 50 хопов/с; запись входа модели по RTT: 8,98 с без пропусков, среднее 0, фон −68 dBFS |
| M2. Живой KWS | сделано частично | инференс 10 раз в секунду идёт; **срабатывание на слова не проверено** — в комнате никто не говорил |
| M3. Always-on | сделано | со сном `awake` 25,7 %, без сна 100,3 %; счётчики стадий совпадают |
| M4. Дашборд | сделано | тесты разборщика; страница проверена на записи с платы; с живой платой отработал 10 минут как приёмник |
| M5. Проверка | частично | 10 минут: `overruns=0`, `dma_faults=0`, слот не менялся, ложных событий 0. Не сделано: 30 минут, 10 слов × 5, пропуск на тишине (отложен по решению владельца) |
| M6. Упаковка | сделано | `README.md`, `PROVENANCE.md`, `make demo`, запись для `make replay` |

Отступления от плана ниже:

- **Инициализация платы полная** (`skip_bsp_init = false`), а не сокращённая,
  как в `kws_pdm`. С сокращённой `am_hal_i2s_enable()` возвращает
  `AM_HAL_STATUS_INVALID_OPERATION`. Причина не установлена: ручная передача
  менеджеру тактов сведений о кварцах и настройки HFRC не помогла.
- **Сборка с хоста.** §1.2 и §3 ниже описывают сборку только в контейнере;
  позже выяснилось, что `nsx` 0.7.17 ставится из PyPI и собирает проект прямо
  на хосте. Актуальный порядок сборки — в `README.md`.
- **Срез фильтра 60 Гц** выбран без сравнения с 20 Гц на записи речи.
- **Слот микрофона** за все прогоны оставался в слове 0 и не менялся, в том
  числе при подключении отладчика по RTT. Определение слота оставлено.
- **SWO иногда теряет перевод строки** (34 склеенные строки из 8215 за
  10 минут). Разборщик дашборда такие строки разделяет; это покрыто тестом.
- **Сторож зависания DMA** написан, но ни разу не сработал, то есть на плате
  не проверен.

## 0. Принятые решения

| Вопрос | Решение |
|---|---|
| `kws_core` | **Копия** внутри `demo_I2S/`, с записью происхождения |
| Микрофон | I2S MEMS, 24 бита, питание 1,6–3,6 В (характеристики в §1.3) |

Остаётся открытым одно: пропуск инференса на тишине. В плане это опция,
выключенная по умолчанию (этап M5).

## 1. Что изучено

### 1.1 Что нужно демо

Демо — это четыре части, и три из них уже существуют в пригодном виде.

| Часть | Что есть | Что делать |
|---|---|---|
| Конвейер KWS (кольца, фронтенд, модель, распознаватель) | `ambiq_kws_examples/kws_core`, 596 КБ с тестами | скопировать без правок |
| Модель | `assets/depgraph_r060_kd_int8.tflite`, SHA `ae08012b…`, вход `[1,49,10,1]` int8 | скопировать вместе с `tools/embed_model.py` |
| Источник звука I2S | только пробная прошивка `demo_b/i2s_mic_test` (без KWS, сборка через `make`) | написать заново под контракт `audio_source.h` |
| Дашборд | `kws_pdm/host/kws_dashboard.{py,html}`, русский интерфейс | перенести, перевести, расширить |

Приёмы always-on, которые `kws_core` уже реализует и которые демо получает
вместе с копией:

| Приём | Параметры из `kws_config.h` |
|---|---|
| Кольцевой буфер PCM, счётчик переполнений | 17 760 отсчётов (1 с + кадр + 4 хопа) |
| Фронтенд считает окно, FFT и mel один раз на хоп | кадр 480, хоп 320, FFT 512, 40 mel, 20–4000 Гц |
| Кольцевой буфер признаков без сдвига памяти | 57 кадров × 40 mel-энергий |
| log и DCT откладываются до инференса | потому что обучение делит клип на его **знаковый** максимум |
| Скользящее окно | 49 кадров, шаг 5 кадров = 100 мс |
| Распознаватель | сглаживание 3, порог 0,70, 2 совпадения подряд, пауза 750 мс |
| Статическая память, один интерпретатор на всё время | арена: занято 16 820 байт (напечатано `kws_pdm`) |
| Счётчики циклов по стадиям | фронтенд, MFCC, квантование, `Invoke` |

Чего в `kws_pdm` нет и что добавляется: сон ядра между хопами, учёт доли
бодрствования, печать всех четырёх счётчиков стадий, строка на каждый
инференс, определение слота микрофона, пропуск стартового переходного
процесса, восстановление после сбоя DMA.

| Сгенерированные сценарии прошивки содержат пути `/workspace/...` | `build/.../jlink/kws_pdm/flash_cmds.jlink` | прошивка с хоста — своим сценарием J-Link с путём хоста (так уже делалось) |

| Модули занимают 297 МБ; `kws_pdm` использует ссылку на `../kws_clip/modules` | `du`, `ls -la` | для `demo_I2S` — ссылка на тот же каталог; свежий клон восстанавливается через `nsx sync` |
| Готовая `libam_hal.a` из nsx SDK экспортирует 21 функцию `am_hal_i2s_*`, а также `am_hal_clkmgr_*` и `am_hal_sysctrl_sleep` | `arm-none-eabi-nm` | драйвер I2S пишется прямо на HAL; запасной путь через `make` не нужен |
| В таблице векторов nsx обработчик I2S0 — слабый символ `am_dspi2s0_isr` (вектор 44) | `nsx-core/src/apollo510/gcc/startup_gcc.c` | обработчик объявляется в приложении под этим именем |
| Макросы `AM_HAL_PIN_47_I2S0_CLK`, `_48_I2S0_WS`, `_4_I2S0_SDIN` есть в nsx SDK | `am_hal_pin.h` | пины настраиваются напрямую, как в пробной прошивке |
| В nsx SDK другая ревизия AmbiqSuite (`stable-2026.06.18`, тег `v5.2.24`), чем в пробной прошивке (`release_sdk5p2p0`) | заголовки HAL | поведение I2S на этой ревизии надо перепроверить в M1, а не считать доказанным |
| `nsx-audio` поддерживает только PDM | `nsx_audio.h` | модуль из `nsx.yml` убирается |
| Буферы DMA размещаются макросом `NSX_MEM_SRAM_BSS` с выравниванием 32 байта | `kws_pdm/src/nsx_audio_source.c`, `memory-placement.md` | то же для буферов I2S |
| `kws_pdm` стартует с `skip_bsp_init = true`, 96 МГц, вывод через ITM | `kws_pdm/src/main.cc` | пробная прошивка вызывала полный `am_bsp_low_power_init()`; работу I2S с минимальной инициализацией проверить в M1 |
| nsx даёт `nsx_power_deep_sleep()`; обычный сон — через HAL | `nsx_power.h` | на первом этапе обычный сон |
| Свой модуль nsx можно зарегистрировать (`nsx module register`) | `custom-modules.md` | не нужно: драйвер I2S остаётся исходником приложения в `src/` |
| Тесты `kws_core` скачивают GoogleTest v1.15.2 через `FetchContent` | `kws_core/CMakeLists.txt` | тестам на хосте при первом запуске нужна сеть |

### 1.3 Микрофон

По характеристикам модуль совпадает с InvenSense INMP441; маркировку на
корпусе стоит сверить, ниже используются только цифры из описания.

| Характеристика | Что из неё следует |
|---|---|
| Питание 1,6–3,6 В | 1,8 В от VDD_MCU подходит, преобразователь уровней не нужен |
| 24 бита, L/R на земле → левый канал | формат 2 × 32 бита, полезные биты [23:0]; второй слот пуст |
| Чувствительность −26 dBFS (при 94 дБ SPL) | обычная речь на 30 см даёт примерно −60…−50 dBFS RMS, пики выше |
| SNR 61 дБА | собственный шум около −87 dBFS; шум округления int16 после сдвига `>> 8` около −98 dBFS, то есть сдвиг `>> 8` ничего не теряет |
| Полоса от 60 Гц | фильтр верхних частот со срезом до 60 Гц не убирает ничего, что микрофон передаёт |

Измерено на плате пробной прошивкой: фон комнаты около −54 dBFS RMS, и в нём
преобладают низкие частоты (сильнее всего 50 Гц, около −65 dBFS). Это уровень
того же порядка, что и речь, поэтому фильтр обязателен: без него максимум
окна, на который делится весь клип, задаёт гул, а не голос.

Сверить по документации микрофона в M1: минимальную частоту SCK (у нас
1,024 МГц) и время выхода на режим после подачи такта (наблюдалось около 2 с).

## 3. Сборка через nsx: шаги

### 3.1 Создание приложения (один раз, этап M0)

1. Скопировать из `kws_pdm`: `nsx.yml`, `CMakeLists.txt`, `Makefile`,
   `.gitignore`, `src/kws_profile_target.c`, `src/apollo510_cache.h`, `rtt/`.
2. Скопировать `kws_core/`, `assets/`, `tools/embed_model.py`; записать в
   `PROVENANCE.md` коммит `ambiq_kws_examples` (сейчас `129b8f7`) и SHA модели.
3. В `nsx.yml`: имя проекта `kws_i2s`, убрать `nsx-audio`; версии `helia-rt`
   (`cfab1523`) и `ns-cmsis-nn` (`b386770a`) оставить как в `kws_pdm`.
4. В `CMakeLists.txt`: `KWS_CORE_ROOT` → `${CMAKE_CURRENT_LIST_DIR}/kws_core`,
   пути к модели и `embed_model.py` — внутрь `demo_I2S`; исходники источника
   звука заменить; убрать `nsx::audio`; опции переименовать в `KWS_I2S_*`.
5. Создать ссылку `modules → ../ambiq_kws_examples/kws_clip/modules`.
6. В контейнере: `nsx lock --app-dir .`, затем
   `script -q -e -c 'nsx configure --app-dir .' /tmp/cfg.log`.
7. Закоммитить `nsx.yml` и новый `nsx.lock`.

Альтернатива шагам 1 и 6 — `nsx create-app --board apollo510_evb`; она
создаёт пустой каркас, и всё равно пришлось бы переносить настройки
`kws_pdm`, поэтому копирование короче и сохраняет проверенные версии.

## 4. Прошивка по компонентам

### 4.1 Драйвер I2S — `src/i2s_audio.h`, `src/i2s_audio_source.c`

Реализует контракт `kws_core/audio/audio_source.h`.

**Константы (`i2s_audio.h`).** Пины 47 / 48 / 4, модуль I2S0, SYSPLL
24 576 000 Гц, BCLK 1 024 000 Гц, 16 000 Гц, блок DMA 640 слов.
`static_assert`: 640 / 2 == `KWS_AUDIO_BLOCK_SAMPLES` (320).

**Инициализация (`AudioSourceInit`).**

1. `am_hal_clkmgr_clock_config(SYSPLL, 24576000)`.
2. `am_hal_gpio_pinconfig` для трёх пинов (функции `I2S0_CLK`, `I2S0_WS`,
   `I2S0_SDIN`).
3. `am_hal_i2s_initialize(0)`, `am_hal_i2s_power_control(ON)`.
4. `am_hal_i2s_configure`: ведущий, только приём, `PLL_FOUT4`, `eDiv3 = 1`,
   стандартный I2S, 2 канала по 32 бита, 24-битные отсчёты.
5. `am_hal_i2s_enable`.

**Запуск (`AudioSourceStart`).** `am_hal_i2s_dma_configure` с двумя буферами
по 640 слов (`NSX_MEM_SRAM_BSS`, выравнивание 32), приоритет и разрешение
`I2S0_IRQn`, `am_hal_i2s_dma_transfer_start`.

**Прерывание (`am_dspi2s0_isr`).** Снять и сбросить статус,
`am_hal_i2s_interrupt_service` (переключает буфер), выставить флаг готовности.
Если флаг ещё стоит — `overruns++`. Звук в прерывании не обрабатывается.

**Основной контекст (`AudioSourceAcquireBlock`).**
`am_hal_i2s_dma_get_buffer(RX)` → сброс кэша данных для диапазона →
`i2s_pcm16` → указатель на хоп из 320 int16.

**Сбой DMA.** `am_hal_i2s_dma_error` → `dma_faults++`, остановка и повторный
запуск передачи, строка в SWO.

Готово, когда: 50 хопов в секунду, `overruns=0`, `dma_faults=0` за 10 минут.

### 4.2 Подготовка сигнала — `audio/i2s_pcm16.h`

Чистый C без заголовков HAL, тестируется на хосте.

| Шаг | Правило | Значение по умолчанию |
|---|---|---|
| Выбор слота | на каждом хопе — слот, где есть ненулевые слова; если оба нулевые или оба ненулевые, оставить прежний и поднять флаг | — |
| Фильтр верхних частот | однополюсный, на 24-битном сигнале, до сужения | срез выбрать в M1 из 20 и 60 Гц по записи |
| 24 → 16 бит | арифметический сдвиг с насыщением | `>> 8` (обоснование в §1.3) |
| Пропуск старта | первые N хопов отдаются нулями, фильтр при этом работает | 100 хопов (2 с) |
| Статистика | пик и среднее хопа, номер слота, флаг смены слота | в `AudioSourceStatus` и строку `Frame` |

Готово, когда: тесты проходят; в записи по RTT после старта среднее в
пределах ±50 единиц int16, речь разборчива.

### 4.3 Главный цикл always-on — `src/main.cc`

Основа — цикл `kws_pdm`.

```
init: nsx_system_init (LOW, кэш, ITM, skip_bsp_init) → KwsProfileInit →
      KwsApp::Init → AudioSourceInit/Start → баннер
loop:
  пока есть готовый хоп (не больше 8 подряд):
      OnAudioBlock(хоп)            # кольцо PCM + один кадр mel
      now_ms += 20                 # время от тактов микрофона
      если InferenceDue: RunInference → строка inf; при событии — строка event
  раз в секунду: строки Frame, stage, live pred
  если хопа нет: сон до прерывания
```

**Сон.** Проверка флага и вход в `am_hal_sysctrl_sleep(NORMAL)` — при
запрещённых прерываниях, чтобы не проспать блок, пришедший между проверкой и
сном. Глубокий сон не используется: не проверено, сохраняются ли PLL и I2S, а
вывод SWO перед ним надо отключать.

**Учёт бодрствования.** Счётчик DWT суммирует циклы вне сна; раз в секунду
печатается `awake=<%>`. Сначала проверить, идёт ли DWT во сне на этой плате:
если останавливается, доля считается как отношение активных циклов к
ожидаемым за секунду.

**Пропуск на тишине (опция, M5).** Если пик окна ниже порога, `Invoke` не
вызывается, распознавателю подаётся «тишина». Фронтенд и кольца работают
всегда.

Готово, когда: со сном события те же, что без сна, `overruns=0`, `awake`
заметно ниже 100 %.

### 4.4 Строки SWO

Формат `kws_pdm` сохранён, разборщик общий.

```
kws_i2s runtime=helia-rt arena_used=<N>
perf_mode=LOW cpu_hz=96000000
i2s backend=hal fs=16000 bclk=1024000 slots=2x32 bits=24 shift=<n> hpf=<Hz>
gpio clk=47 ws=48 sdin=4
model sha256=<64 hex>
Frame <N>  peak=<n> dc=<n> overruns=<n> dma_faults=<n> slot=<0|1> awake=<%>
stage frontend_cycles=<n> mfcc_cycles=<n> quantize_cycles=<n> invoke_cycles=<n>
live pred=<label> score=<s> fired=<0|1> invoke_cycles=<n> invoke_us=<n>
inf pred=<label> score=<s>
event label=<label> score=<s>
```

`Frame`, `stage`, `live pred` — раз в секунду; `inf` — на каждый инференс
(опция); `event` — сразу. На этой плате SWO уже терял первый байт и склеивал
строки, поэтому пропускная способность со строками `inf` измеряется в M2.

### 4.5 Выгрузка звука по RTT — `src/kws_i2s_rtt.c`, `host/rtt_pcm_dump.py`

Канал 1, int16, 16 кГц — тот хоп, который получает модель. Буфер не больше
250 мс, чтобы запись не начиналась со старого звука. Скрипт пишет WAV и
печатает уровень по секундам.

## 9. Что демо вправе утверждать

- Распознавание с живого микрофона — не точность на наборе данных; счёт
  попыток в `results/` не пишется.
- `invoke_cycles`, `stage`, `awake` — счётчики этой прошивки на плате; с
  heliaPROFILER и цифрами хоста не сравниваются.
- «Спит N % времени» не означает «потребляет на N % меньше»: ток не
  измеряется.
- Результат с микрофона не сравнивается с клипом из флеша или UART.

## 10. Риски

| Риск | Что делаем |
|---|---|
| I2S ведёт себя иначе на ревизии SDK из nsx или при `skip_bsp_init` | первая проверка M1; при расхождении — полный `am_bsp_low_power_init()` |
| Слот микрофона меняется на ходу | определяем на каждом хопе, печатаем `slot=`; в M1 выясняем, бывает ли это без остановки ядра отладчиком |
| Гул 50 Гц задаёт максимум окна | фильтр; срез выбирается по записи в M1 |
| Сон ломает захват или SWO | сон — опция; сравнение счётчиков со сном и без |
| SWO не успевает за строками `inf` | измерение в M2; при искажениях опция выключена |
| Копия `kws_core` расходится с оригиналом | коммит в `PROVENANCE.md`; правки копии запрещены без записи |
| Модель обучена на GSC, а не на этом микрофоне | живая доля распознавания может быть заметно ниже; сообщаем как есть |
| GPIO 47 / 48 в BSP заняты также IOM5 и UART2 RX | в демо не используются; отметить в README |
